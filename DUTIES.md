# Duties and Responsibilities for Graph Neural Network Subgraph Sampler Agent

## Dual-Control Architecture
Maker:
subgraph-random-walker

Checker:
unbiased-weight-checker

## Operational Workflow
1. The Maker (subgraph-random-walker) analyzes incoming telemetry, context, and requirements.
2. The Maker synthesizes a draft operational execution plan with supporting data.
3. The Checker (unbiased-weight-checker) independently verifies all assumptions and constraints.
4. If validation passes, the plan is signed, logged, and committed.
5. All actions are appended to the immutable governance audit trail.
